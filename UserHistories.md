# História do usuário

## História do usuário
| ID     | Ator             | Descrição de histórias                                                                         |
| ------ | ---------------- | ---------------------------------------------------------------------------------------------- |
| HU-001 | Usuário Employee | Eu quero poder cadastrar minhas despesas.                                                      |
| HU-002 | Usuário Employee | Eu quero poder validar o status de minhas despesas cadastras anteriormente.                    |
| HU-003 | Usuário Employee | Eu quero poder ver o histórico das minhas despesas cadastradas.                                |
| HU-004 | Usuário Manager  | Eu quero poder ver todas as despesas cadastradas pelo meu time.                                |
| HU-005 | Usuário Manager  | Eu quero poder filtrar as despesas cadastradas por busca, ordem cronológica e ordem alfabética |
| HU-006 | Usuário Manager  | Eu quero poder analisar e validar as despesas enviadas pelo meu time                           |
| HU-007 | Usuário Finance  | Eu quero poder analisar e validar as despesas enviadas pelos departamentos                     |
| HU-008 | Usuário Finance  | Eu quero poder gerenciar alertas de violação de regras                                         |
| HU-009 | Usuário Finance  | Eu quero poder analisar e validar os alertas gerados pelo sistema                              |
| HU-010 | Usuário Finance  | Eu quero poder ver os orçamentos dos departamentos                                             |
| HU-011 | Usuário Finance  | Eu quero poder editar o orçamento dos departamentos                                            |
| HU-012 | Usuário Finance  | Eu quero poder visualizar relatórios                                                           |
| HU-013 | Usuário Finance  | Eu quero poder exportar e baixar os relatórios gerados                                         |

## Critério de aceite

| ID     | Passos da história                                                                                                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HU-001 | Entra no sistema, entra na aba de **Despesas**, entra em **Cadastro de despesas**, insere os dados da despesa.                                                                                                |
| HU-002 | Entra no sistema, entra na aba de **Despesas**, entra na área de **Despesas ativas/pendentes** e verifica seus status.                                                                                        |
| HU-003 | Entra no sistema, entra na aba de **Despesas**, entra no **Histórico de despesas** e verifica as despesas cadastradas que estão pendentes, rejeitadas ou aprovadas.                                           |
| HU-004 | Entra no sistema, entra na aba do **Departamento**, entra no **Histórico de despesas** e verifica todas as despesas cadastradas pelo time do departamento e seus status.                                      |
| HU-005 | Entra no sistema, entra na aba do **Departamento**, entra no **Histórico de despesas**, aplica filtros para facilitar a busca.                                                                                |
| HU-006 | Entra no sistema, entra na aba do **Departamento**, entra em **Despesas ativas/pendentes**, analisa os dados da requisição e faz a validação final, aceitando ou rejeitando.                                  |
| HU-007 | Entra no sistema, entra na aba de **Despesas por departamento**, seleciona o **Departamento** com despesas pendentes, analisa os dados da requisição e faz a validação final, aceitando ou rejeitando.        |
| HU-008 | Entra no sistema, entra na aba de **Alertas**, entra no **Gerenciar alertas**, seleciona uma possível violação e edita suas condições e seu texto de alerta.                                                  |
| HU-009 | Entra no sistema, entra na aba de **Alertas**, entra no **Lista de Alertas**, verifica e valida os alertas e seus status e faz a validação final, marcando ele como resolvido ou deixando o alerta como novo. |
| HU-010 | Entra no sistema, entra na aba de **Orçamentos**, valida os departamentos e seus respectivos orçamentos.                                                                                                      |
| HU-011 | Entra no sistema, entra na aba de **Orçamentos**, entra em **Edição de orçamentos**, altera o orçamento do departamento desejado e salve.                                                                     |
| HU-012 | Entra no sistema, entra na aba de **Relatórios**, selecione o tipo de relatório e visualize o relatório exibido.                                                                                              |
| HU-013 | Entra no sistema, entra na aba de **Relatórios**, selecione o tipo de relatório e visualize o relatório exibido, realize a exportação do relatório no formato CSV/JSON                                        |
